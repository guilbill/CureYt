# CureYt V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Static web page that signs in with Google and ranks recent videos from the user's YouTube subscriptions by overperformance versus their own channel.

**Architecture:** No backend, no build step. Native ES modules served by GitHub Pages. Google Identity Services token client for auth, YouTube Data API v3 via `fetch`, IndexedDB for the cache. Pure logic (`score.js`) and orchestration (`sync.js`, with injected `api` and `cache`) are unit-tested with `node --test`.

**Tech Stack:** HTML, CSS, vanilla JS modules, IndexedDB, Google Identity Services. Node 20+ only for tests.

**Spec:** "Spec V1 — Classement des meilleures vidéos de mes abonnements YouTube" (claude.ai artifact UcppsDmK4XkZDvb49vUxkb), summarised in the constraints below.

## Global Constraints

- Scope `https://www.googleapis.com/auth/youtube.readonly`, no secret, no API key; only a public OAuth client ID in `config.js`.
- Never call `search.list`. Four calls only: `subscriptions.list`, `channels.list`, `playlistItems.list` (uploads), `videos.list`.
- Shorts = duration <= 180 s. Lives/premieres = `liveStreamingDetails` present or `liveBroadcastContent != none`. Missing `viewCount` = dropped.
- Max 6 parallel requests. 50 ids per `channels.list` / `videos.list`.
- Score params: tau 3 d, f_min 0.15, m 5, min ref age 7 d, sample 30, r0 0.05, alpha 0.15, lambda 0.02. Confidence: high n>=15, medium 5..14, low <5 ("peu de données" badge).
- Periods 3/7/14/30 days, default 7. Changing period never calls the API.
- Refresh rules: full if first visit or refs > 7 d; light if data > 3 h; subscriptions every 24 h. Full load for 200 subs <= 450 units, light ~240.
- Errors: 403 quotaExceeded, 401 (re-request token, retry), network (2 retries then "Réessayer"). Cache stays displayed in all cases.
- "Effacer mes données" empties the 3 stores and revokes the token. Light/dark theme, usable on phone. UI text in French.

## Review Focus

- Channel with hidden subscribers or 0 subscribers: reference falls back to median of M, never NaN/Infinity.
- Channel with n = 0 eligible reference videos: smoothed reference equals P, no division by zero.
- Video with 0 views or age under f_min threshold: finite score, no -Infinity.
- Evaluated video is excluded from its own reference, and the confidence uses the n actually used.
- Deleted video (absent from `videos.list`) and playlist 404 (empty channel) do not abort the whole sync.
- Account switch on the same browser: subscription sync on login prunes channels that are no longer subscribed.
